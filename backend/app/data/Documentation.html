Tier 0: Data Foundation

Clean, validated, time-ordered data base

Foundation
Why This Matters

A clean data foundation is critical for time-series prediction. Garbage in = garbage out.

🔧 Processing Steps

Date Parsing & Sorting
Convert dates to datetime, sort chronologically. Ensures no future data leakage.
df["Date"] = pd.to_datetime(df["Date"], dayfirst=True)
df = df.sort_values("Date").reset_index(drop=True)
Team Name Standardization
Standardize team names across seasons (e.g., "Man United", "Manchester Utd", "Man Utd").
team_mapping = {
  "Man United": "Manchester United",
  "Spurs": "Tottenham",
  ...
}
df["HomeTeam"] = df["HomeTeam"].map(team_mapping)
Missing Value Handling
Fill missing stats with 0, drop matches with missing essential data.
# Stats columns: fill with 0
df[stats_cols] = df[stats_cols].fillna(0)
# Essential columns: drop if missing
df = df.dropna(subset=["Date", "HomeTeam", "AwayTeam", "FTR"])
Target Variable Creation
Convert FTR to numeric target for ML models.
df["target"] = df["FTR"].map({"H": 0, "D": 1, "A": 2})
# 0 = Home Win, 1 = Draw, 2 = Away Win

Tier 1: Core Team Strength

Intrinsic team quality metrics

Essential Features

🏆 Feature Specifications

home_elo_pre / away_elo_pre
Enhanced Elo rating before match. Goal difference weighted, home advantage adjusted.
# Enhanced Elo with goal margin
goal_margin_weight = min(1.0, (abs(GD) + 1) / 3)
K_effective = BASE_K * goal_margin_weight
elo_diff_pre
Elo difference (home - away). Positive = home team stronger.
Range: Typically -500 to +500
home_ppg_current / away_ppg_current
Points per game in current season. Weighted by match recency.
PPG = Σ(points) / matches_played
# Recent matches weighted 1.5x
home_ppg_home / away_ppg_away
Home/Away specific PPG. Teams perform differently home vs away.
Example: Some teams are strong at home but weak away.
goal_diff_ratio
Goals scored vs conceded ratio. Measures team balance.
ratio = goals_scored / (goals_conceded + 1)
# +1 to avoid division by zero
attack_strength / defense_strength
Relative to league average. League-normalized metrics.
attack_strength = team_goals_scored / league_avg_goals
defense_strength = team_goals_conceded / league_avg_goals_conceded

Tier 2: Form & Momentum

Short-term team state and trends

Advanced Features

📈 Feature Specifications

home_form_last5 / away_form_last5
Weighted points from last 5 matches. Recent matches weighted more heavily.
weights = [0.5, 0.6, 0.7, 0.8, 1.0] # Most recent = 1.0
weighted_points = Σ(points_i × weight_i) / Σ(weights)
goal_diff_trend
Goal difference trend: Last 3 matches vs previous 3.
trend = GD_last_3 - GD_previous_3
# Positive = improving defense/attack
xg_proxy_last5
Expected goals proxy based on shots data.
xG = (shots_on_target × 0.3) + (shots × 0.02)
# Professional approximation
clean_sheet_rate_last5
Proportion of clean sheets in last 5 matches.
rate = clean_sheets / 5
clean_sheet = 1 if goals_conceded == 0
failed_to_score_rate_last5
Proportion of matches failed to score.
Identifies teams with scoring problems.
btts_rate_last5
Both teams scored rate. Indicates open/defensive games.
High rate = open games, both teams attack
shot_accuracy_last5
Shots on target / total shots ratio.
accuracy = Σ(shots_on_target) / Σ(total_shots)
# Higher = more clinical team
points_ewma
Exponentially weighted moving average of points.
decay = 0.85
EWMA = Σ(points_i × decay^i) / Σ(decay^i)

Tier 3: Context & Edge

Situational and psychological factors

Professional Edge

🎭 Feature Specifications

h2h_win_rate_last3
Head-to-head win rate in last 3 meetings (same teams).
Some teams have psychological edges over specific opponents.
h2h_goal_diff
Goal difference in last 5 head-to-head matches.
Positive = historical dominance in this fixture.
is_derby
Binary indicator for derby matches (geographic proximity).
derbies = {
  "Manchester United": ["Manchester City"],
  "Liverpool": ["Everton"],
  ...
}
days_since_last_match
Days rest since team's previous match.
days_rest = current_date - previous_match_date
# < 3 days = potential fatigue, > 7 days = potential rust
season_phase
Match timing within season (early/middle/late).
Early season = unpredictable, Late season = predictable
table_position_diff
Difference in league table positions.
Proxy for team strength difference at that moment.
